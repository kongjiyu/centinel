# Centinel Design Context

- **Audience:** QA engineers, testers, developers, SMEs, and FYP evaluators.
- **Use cases:** configure AI providers, manage projects, run static and dynamic tests, inspect evidence, debug failures, and export reports.
- **Brand personality:** precise, technical, evidence-driven, trustworthy, calm, and operational.
- **Visual direction:** a dark aerospace-inspired QA command center using cyan structure and lime verified states, without generic cyberpunk decoration.

The complete and authoritative design specification is [`DESIGN.md`](./DESIGN.md). Read it before any design work.
